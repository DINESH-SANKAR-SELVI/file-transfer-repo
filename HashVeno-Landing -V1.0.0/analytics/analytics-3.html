Identified users
Tier 3 · consented
About consent
DPDP compliance status

Anonymous analytics (Tier 1) runs without consent. Behavioral analytics (Tier 2) and identified-user tracking (Tier 3) require consent via the banner.

Users who have accepted analytics tracking appear in Identified Users. Each consent record stores the timestamp, IP hash, and which categories were approved.

To remove a user's data per DPDP request: send a POST to /api/user/:persistent_id/delete with dashboard credentials. The endpoint purges events, sessions, and identified records.
